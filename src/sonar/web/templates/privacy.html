Sonar is a self-hosted application for a private household, available only to its owner and listed household members.

It reads the owner's own bank account data via Enable Banking and stores it only in the owner's own database.

Nothing is shared with, sold to or sent to any third party.

The owner can delete the data at any time by deleting that database.
